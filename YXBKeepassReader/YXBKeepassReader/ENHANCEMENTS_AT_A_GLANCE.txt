   → User is informed before opening

	 ✓ Step 6: Click Save
	 ✓ Step 7: Come back to KeePass Reader
	 ✓ Step 8: Select the XML file

6. Export as XML
7. Come back to Reader, Select File
   → File browser now suggests XML files
   → Easy to find exported XML
8. Click Open Database
