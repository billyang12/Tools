## Step-by-Step Guide

### 1. Open a PDF File

1. Click **📂 Open PDF** button
2. Select your PDF file
3. The **first page appears on screen** - you'll see the actual PDF content!
4. File info shows in right sidebar

**You'll now see:**
- The PDF page rendered in the center
- Page navigation at top
- Editing tools on left
- Properties on right

### 2. Navigate Pages

- **Previous/Next buttons** - Move through pages
- **Page indicator** - Shows "Page X of Y"
- **Zoom controls** - +/- buttons to zoom in/out
- Current page is **always visible**

### 3. Edit Text - Click Mode

**To Add New Text:**

1. Click **"Edit Text"** radio button at top
2. Your cursor changes to I-beam (text cursor)
3. **Click anywhere on the PDF** where you want text
4. A dialog appears - type your text
5. Click OK
6. You'll see a **yellow highlight** showing where text will be added
7. Continue clicking to add more text

**Font Options:**
- Adjust **Font Size** slider (8-72pt)
- Choose **Font Family** (Helvetica, Times, Courier)
- Select **Text Color** (Black, Red, Blue)

### 4. Add Images - Click Mode

**To Add an Image:**

1. Click **📷 Select & Add Image** button
2. Choose an image file (JPG, PNG, BMP)
3. Click **"Add Image"** radio button at top
4. **Click on the PDF** where you want the image
5. Enter size (width and height)
6. Click OK
7. You'll see a **blue outline** showing where image will be placed

**Image Tips:**
- Images are placed at exact click position
- Size is in PDF points (72 points = 1 inch)
- Recommended: 100-200 for small images, 300-500 for larger

### 5. Erase Content - Drag Mode

**To Remove Text or Images:**

1. Click **"Erase"** radio button at top
2. Your cursor changes to "No" symbol
3. **Click and drag** to select the area to erase
4. You'll see a **red selection rectangle**
5. Release mouse - the area is marked for erasing
6. A white rectangle will cover that area when saved

### 6. Save Your Changes

1. Click **💾 Save Changes** button
2. Choose where to save the edited PDF
3. **All your edits are applied** to create new PDF
4. Option to open the saved PDF immediately

**Important:** 
- Original PDF is **never modified**
- Each edit is tracked in "Recent Edits" list
- You can see how many edits are pending

## Tips and Tricks

### For Best Results

1. **Zoom In** - When placing text/images precisely, zoom to 150-200%
2. **Use Select Mode** - When just viewing, stay in Select mode
3. **Small Erases** - Make small erase selections for precision
4. **Font Size** - Use 12pt for body text, 18-24pt for titles
5. **Image Size** - Test with one page before adding to all pages

### Coordinate System

- **X** - Increases left to right (0 = left edge)
- **Y** - In PDF, 0 is at bottom (we handle conversion for you!)
- **Mouse Position** - Shows in bottom-right of status bar

### Visual Feedback

- **Yellow highlight** = Text will be added here
- **Blue dashed box** = Image will be placed here
- **Red selection** = Area will be erased
- **Edit count** = Shows in status bar

### Keyboard Tips

While editing:
- **Mouse drag** - Select area (in Erase/Select mode)
- **Click** - Add content (in Text/Image mode)
- **Escape** - Cancel current operation (planned)

## Troubleshooting

### "PDF doesn't appear"
- Wait a moment - large PDFs take time to render
- Try zoom out if only seeing partial page
- Check if file is corrupted

### "Can't click to add text"
- Ensure "Edit Text" mode is selected
- Check if cursor is I-beam
- Try clicking different areas of page

### "Image doesn't show up"
- Make sure you clicked "Select & Add Image" first
- Verify image file is valid
- Check the "Add Image" mode is selected

### "Edits disappeared"
- Visual markers are temporary - they show where edits will go
- Actual edits are applied when you Save
- Check "Recent Edits" list to see what's pending

### "Save fails"
- Ensure you have write permission to output folder
- Check disk space is available
- Verify original PDF isn't corrupted

## What's Happening Behind the Scenes

1. **PDF Rendering** - PdfiumViewer renders each page as high-res image
2. **Click Detection** - Your clicks are converted to PDF coordinates
3. **Edit Tracking** - All edits stored in memory until save
4. **Batch Processing** - On save, all edits applied using iText7
5. **New File Creation** - Original never modified
