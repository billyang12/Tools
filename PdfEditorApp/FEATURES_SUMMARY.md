## 🚀 Quick Access Guide

### Most Common Tasks

#### 1. Edit Text in a PDF
```
1. Click "✏️ Edit Content" button
2. Open your PDF
3. Enter Find/Replace text
4. Click "Replace Text"
5. Save edited PDF
```

#### 2. Add an Image to PDF
```
1. Open Content Editor
2. Click "Select Image File"
3. Choose your image
4. Click "Add Image at Cursor"
5. Set position and size
6. Save
```

#### 3. Merge PDFs
```
1. Click "🔗 Merge" button
2. Select multiple PDFs (hold Ctrl)
3. Choose output filename
4. Save
```

#### 4. Protect PDF with Password
```
1. Open PDF
2. Click "🔒 Encrypt"
3. Enter passwords
4. Save encrypted PDF
```

## 💡 Tips & Tricks

### Content Editing
1. **Precise Positioning**: Use the Element List to find exact coordinates
2. **Test First**: Try on a copy before editing important documents
3. **Coordinate System**: Remember Y increases from bottom to top
4. **Image Size**: Keep images under 500x500 for best results
5. **Font Sizes**: Use 12pt for body text, 24pt+ for headers

### General Usage
1. **Always Save As**: Never overwrite originals
2. **Use Descriptive Names**: e.g., "contract_v2_edited.pdf"
3. **Check Results**: Open edited PDFs to verify changes
4. **Batch Operations**: Use Merge for combining many files
5. **Security**: Use encryption for sensitive documents
